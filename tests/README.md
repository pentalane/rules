# 準拠テストのケース集

[cases.json](cases.json) は、ペンタレーンの実装が [公式ルール](../rules.md) に従っているかを確かめるためのケース集です。言語に依存しない JSON なので、どの言語の実装のテストにも読み込めます。

ライセンスは [CC0 1.0](LICENSE) です。表示なしで、実装のテストにそのまま取り込めます。

## 中身

- `placement`：そのカードをそのレーンに置けるかどうか
- `resolve`：1本のレーンの解決（攻撃と守備の判定、比べる数字、ダメージ）

4すくみ（有利・不利・等倍）、同値、Aの特別ルール、ジョーカー（数字のレーン、絵札のレーン、Aのレーン）、守備どうし、直撃を網羅しています。ラウンドの流れ（補充、パスの入れ替え、山札切れなど）は含みません。

## 形式

```json
{
  "rules": "v1.0",
  "license": "CC0-1.0",
  "placement": [ ... ],
  "resolve": [ ... ]
}
```

`rules` は、このケース集が対応する公式ルールの版です。

### カードの書き方

文字列で、数字（`A` `2`〜`10` `J` `Q` `K`）のあとにスーツ（`♠` `♥` `♦` `♣`）を書きます。ジョーカーは `"JK"` です。

例：`"Q♠"`、`"10♥"`、`"A♦"`、`"JK"`

レーン札がジョーカーになることはありません（ルールでめくり直すため）。

### placement

```json
{ "id": "place-ace-on-king", "description": "Kのレーンにも A は置ける", "lane": "K♦", "card": "A♥", "expected": true }
```

| キー | 意味 |
|---|---|
| `id` | ケースの名前（ファイルの中で一意） |
| `description` | 何を確かめるケースか（日本語） |
| `lane` | レーン札 |
| `card` | 置こうとする手札 |
| `expected` | 置けるなら `true`、置けないなら `false` |

そのレーンの自分側が空いている前提です（同じレーンに2枚目は置けません）。

### resolve

```json
{
  "id": "pierce-advantage",
  "description": "ルール本文の例。♠は♥に有利なので攻撃が2倍（24対8）。差分16が貫通",
  "lane": "5♠",
  "cards": ["Q♠", "8♥"],
  "expected": { "positions": ["attack", "defense"], "outcome": "pierce", "values": [24, 8], "damage": { "to": 1, "amount": 16 } }
}
```

2人のプレイヤーを席 `0` と席 `1` で表します。配列はいつも `[席0, 席1]` の順です。

| キー | 意味 |
|---|---|
| `lane` | レーン札 |
| `cards` | 各席がそのレーンに置いたカード。置いていなければ `null` |
| `expected.positions` | 各席のカードが攻撃（`"attack"`）か守備（`"defense"`）か。置いていなければ `null` |
| `expected.outcome` | 結果の種類（下の表） |
| `expected.values` | 比べる数字（下の表）。比べないときは `null` |
| `expected.damage` | ダメージを受ける席（`to`）とその量（`amount`）。ダメージがなければ `null` |

`outcome` の種類：

| 値 | ルールでの名前 | `values` |
|---|---|---|
| `"direct"` | 直撃（攻撃と相手なし） | `null`（ダメージは攻撃の数字） |
| `"pierce"` | 攻撃が守備を上回り、差分を与える | 4すくみの×2をかけた後の数字 |
| `"offset"` | 攻撃と守備が同値で相殺 | 4すくみの×2をかけた後の数字 |
| `"blocked"` | 守備が上回り、攻撃が防がれる | 4すくみの×2をかけた後の数字 |
| `"clash"` | 攻撃どうしで、大きい方が差分を与える | 両者の数字（×2はかけない） |
| `"mutual"` | 攻撃どうしの同値で相打ち | 両者の数字 |
| `"aceWin"` | Aが絵札に勝つ（Aが攻撃） | `null`（ダメージは絵札の数字） |
| `"aceBlock"` | Aの守備が絵札の攻撃を防ぐ | `null` |
| `"none"` | 何も起きない（置いていない、守備だけ、守備どうし） | `null` |

ジョーカーの数字はレーン札の数字として書きます（例：レーン札が♠9なら `values` の中のジョーカーは `9`）。

## 使い方

1. `cases.json` を読み込みます。
2. カードの文字列を、実装のカードの表し方に直します。
3. `placement` の各ケースで、置けるかどうかの判定が `expected` と一致するか確かめます。
4. `resolve` の各ケースで、1レーンの解決の結果を上の形に直し、`expected` と一致するか確かめます。

ルールの版が上がると、ケースが増えたり変わったりします。`rules` の値で、どの版のケースかを確かめてください。
