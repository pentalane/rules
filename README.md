# ペンタレーン 公式ルール

ペンタレーン（PentaLane）は、トランプ1組（52枚）とジョーカー2枚で遊ぶ、2人対戦の5レーンカードゲームです。

このリポジトリは、ペンタレーンのルールの**正本**です。ここにある [rules.md](rules.md) が公式ルールで、ほかの場所にあるルールの説明やアプリは、このルールに準拠するものとして扱います。ウェブで遊べる [pentalane.com](https://pentalane.com) も、準拠する実装の1つです。

- **最新版：v1.0**（2026-10-29） → [rules.md](rules.md)
- 変更の記録 → [CHANGELOG.md](CHANGELOG.md)
- 名前の使い方 → [NAMING.md](NAMING.md)
- 準拠テストのケース集 → [tests/](tests/)

## 実物で遊べること

公式ルールは、**実物のトランプとLPを書くメモだけで遊べる**ことを保ちます。持ち時間、切断、レーティングのように、アプリにしかできない仕組みは公式ルールに入れません。そうした仕組みは、それぞれの実装が公式ルールとは別に決めます。

## 版の付け方

版は `vX.Y` または `vX.Y.Z` で表し、git のタグを打ちます。

| 変更 | 版の上げ方 | 例 |
|---|---|---|
| 表現だけの修正（誤字、言い回し、例の追加など。遊び方は変わらない） | 3つ目の数字を上げる | v1.0 → v1.0.1 |
| ルールの変更（遊び方が変わる） | 2つ目の数字を上げる | v1.0 → v1.1 |
| 大きなルールの変更（前の版と考え方から違う） | 1つ目の数字を上げる | v1.x → v2.0 |

ルールが変わる版（v1.1、v2.0 など）では、`tests/cases.json` もあわせて直します。表現だけの修正では、準拠テストの結果は変わりません。

## ルールの決め方

- ルールは運営が決めます。
- 意見、質問、分かりにくいところの指摘は [Issue](https://github.com/pentalane/rules/issues) でお寄せください。すべての意見を採用するとは限りません。
- 採用していないルールの案（バリアント）は、今のところこのリポジトリに載せていません。

## 準拠の名乗り方

アプリ、ルールブック、大会などで、次の条件を満たしていれば「**ペンタレーン 公式ルール v1.0 準拠**」のように名乗れます。

1. 名乗る版の [rules.md](rules.md) のルールを、変えずに使っている（アプリだけの仕組み、たとえば持ち時間を足すのは構いません。ルールそのものは変えないでください）
2. アプリなどのプログラムの場合は、名乗る版の [tests/cases.json](tests/cases.json) のケースをすべて満たしている
3. 名乗る版を明記し、このリポジトリへのリンクを載せている

ルールを変えたものの扱いは [NAMING.md](NAMING.md) を見てください。
